소개

12년간 IT/SW·AI 교육 콘텐츠를 기획·개발해온 콘텐츠 기획자입니다. 교육 현장에서 커리어를 시작해 컴퓨터공학 전공과 SW 개발 경험을 토대로 콘텐츠의 기술적 정확성을 직접 검증할 수 있으며, 네이버 엔트리·플레이랩스에서 SW교육 콘텐츠를, 다산북스·한빛미디어에서 교육 도서와 강의 자료를 기획·집필·제작해 왔습니다.

특히 생성형 AI를 콘텐츠 제작 전반에 적극 활용하고, Claude Code를 이용해 업무용 도구를 직접 개발·운영하며, 커리큘럼 설계부터 강의·교재·실습 자료 제작까지 한 흐름으로 수행할 수 있습니다. 코드를 이해하고 AI를 도구로 쓰는 콘텐츠 기획자로서 IT 전문성과 학습 효과를 동시에 끌어올릴 수 있으며, 현재 연세대학교 교육대학원 AI융합교육 석사과정을 통해 학습과학·교수설계 이론까지 함께 다지고 있습니다.

01

핵심 역량

/ 01

개발 기반의 정확성

컴퓨터공학을 전공하고 교육 현장에서 커리어를 시작했습니다. SW 개발 실무 경험도 있어 코드를 직접 읽고 실행해볼 수 있기 때문에, 기술 콘텐츠의 정확성을 저자·전문가와 같은 눈높이에서 검증합니다. 개발 경험이 콘텐츠 품질로 이어지는, 기술을 아는 기획자입니다.

/ 02

AI 도구 실무 활용

Cursor·Claude Code 등 다양한 AI 도구를 일상 업무에 활용합니다. 시장조사·아이템 분석·원고 자동화·교정 보조까지 출판 실무 도구(리리가 도와줌)를 직접 만들어 쓰고, 자료 조사·원고 검토·데이터 정리까지 AI를 실무 워크플로우에 녹여 생산성을 높입니다.

/ 03

기획부터 제작까지 전 과정

커리큘럼·콘텐츠 기획부터 교안·강의자료·실습 제작, 교재 집필·편집, 일정 관리까지 콘텐츠 제작 전 과정을 담당합니다. 다산북스에서 아동 SW교육 도서 4권 중 2권을 전 과정 단독 수행했습니다.

/ 04

이론적 토대

연세대 교육대학원 AI융합교육학과 석사과정에서 학습과학·교수설계를 연구합니다. 10년간 현장에서 쌓은 SW·AI 교육 경험을 학문적으로 체계화하고, 다수의 교육 과정과 교사용 수업 자료를 직접 기획·제작한 실전 역량이 뒷받침합니다.

02

케이스 스터디

문제를 어떻게 정의하고 풀었는지 보여주는 두 가지 사례입니다.

Case A · 사이드 프로젝트 · Claude Code

편집자가 직접 만든 출판 실무 도구

리리가 도와줌

배경
신간을 기획하려면 경쟁 도서와 시장 흐름을 알아야 합니다. 서점 사이트를 검색하고 결과를 엑셀에 옮기는 수작업이 기획편집자의 기본 루틴이었습니다.
문제
조사 결과가 어디에도 쌓이지 않았습니다. 기획 건마다 같은 조사를 반복했고, 지난 분석과 비교할 수도 없었습니다.
접근
Claude Code로 직접 설계·개발했습니다. 베스트셀러 데이터 약 2만 9천 건을 누적 수집하고, 55개 IT 카테고리를 분류해 22개 분석 패널로 구성한 단일 HTML 도구를 만들었습니다.
결과
시장조사·아이템 분석·저자 리서치를 도구 하나에서 처리합니다. 반나절 걸리던 경쟁 도서 조사가 몇 분 안에 끝나고, 데이터가 쌓일수록 분석이 정교해집니다.

Case B · 기획·집필·편집 전 과정

기획부터 편집까지 전 과정 단독 수행

골드랜드 시리즈

배경
아동 SW교육 도서는 흥미로운 스토리, 코딩의 정확성, 교육과정 연계라는 세 가지 조건을 동시에 만족해야 합니다.
문제
기획·집필·편집이 분업되면 스토리, 코드, 교육과정 연계가 단계마다 조금씩 어긋나기 쉽습니다. 아이들이 읽는 책일수록 이 틈이 학습 경험을 무너뜨립니다.
접근
모험 스토리 기반 16차시 커리큘럼을 직접 설계하고, 집필·코드 전수 검증·편집·조판까지 단독으로 수행했습니다. 교사용 교수안 56p, 차시별 PPT·실습파일·YouTube 영상까지 제작했습니다.
결과
시리즈 총 3권 출간(모험! 골드랜드, 차원의 골드랜드 1·2). 도서·수업자료·영상이 연결된 완결형 교육 패키지로 완성했습니다.
